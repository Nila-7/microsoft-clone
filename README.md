# Microsoft Clone

A simple Microsoft-inspired landing page built with HTML5 and CSS3. The page recreates a clean product homepage with navigation, a Microsoft 365 hero section, product cards, and a promotional banner.

## Features

- Microsoft-inspired header and navigation menu
- Hero section highlighting Microsoft 365
- Product cards for Microsoft 365, Teams, and Windows
- Product images and “Learn more” links
- Promotional banner section
- Hover effects on navigation links, buttons, and product cards
- Footer with basic navigation links

## Built With

- HTML5
- CSS3

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Nila-7/microsoft-clone.git
   ```

2. Open the project folder.
3. Open `microsoft.html` in your web browser.

No additional packages or build tools are required.

## Project Structure

```
microsoft-clone/
└── microsoft.html
```

## Notes

- This is an educational front-end practice project.
- Product images are loaded from Unsplash, so an internet connection is required to display them.
- The navigation links, buttons, and product links are visual/demo elements; no backend or real Microsoft services are connected.
